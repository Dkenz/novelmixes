
# Novel Mixes MVP Roadmap

## Phase 0 Design
- Finalize brand assets and core wireframes
- UX flows for creator and listener

## Phase 1 Foundation (2–4 weeks)
- React Native skeleton
- Firebase project and auth
- Basic streaming proof of concept (WebRTC/Agora)
- Simple home feed and player screen

## Phase 2 Core Features (4–8 weeks)
- Creator Go Live flow
- Genre and enhanced tag
- Live chat and reactions
- Listener home feed and discovery
- Basic analytics for creators

## Phase 3 Testing and Polish (2–4 weeks)
- Closed beta with 10 creators and 100 listeners
- Instrument latency and retention metrics
- Fixes, UX polish, onboarding flows

## Phase 4 Launch Prep
- App Store and Play Console setup
- Demo video and landing page
- Investor materials

## Notes
- Prioritize low-latency audio and stability
- Keep enhanced streams creator-tagged at launch
