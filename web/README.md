# Novel Mixes — Web

**Go Live. Connect. Earn.**

Interactive web app for Novel Mixes: landing, live rooms, watch (DJ Nightwave and more), chat, follow/like/gifts, Go Live with camera, and sign-in (Google, X, email).

This sits alongside the React Native app in `/mobile` and Firebase functions in `/backend`. It is the branded web experience matching the Novel Mixes mockups.

## What's here

- Landing: "Go Live. Connect. Earn."
- Discover feed by Music, Gaming, Talk, IRL
- Live room with stage, chat, follow, like, gifts
- Go Live (title, category, audience, camera)
- Auth: Google, X, email/password
- Creator profile and activity

## Stack

React 19, TanStack Start, Tailwind v4, Postgres (Neon in production).

## Local

```bash
cd web
npm install
npm run dev
```
